Mercado da Bete

Sobre o projeto:

Sistema web desenvolvido para ajudar o Mercado da Bete a organizar pedidos e entregas.

Funcionalidades:
Cadastro de pedidos.
Consulta de pedidos.
Acompanhamento do status das entregas.
Organização dos dados dos clientes.

Objetivo:
Facilitar o atendimento, reduzir erros e melhorar a organização do mercado.

Tecnologias:
HTML
CSS
JavaScript
Projeto


Este sistema é um protótipo inicial de um MVP acadêmico.
